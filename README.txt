2) ภาพรวมโปรเจกต์
โปรเจกต์นี้เป็นเว็บสำหรับจัดการข้อมูลสินค้า ทำขึ้นมาเพื่อแสดงการทำงานในมุมมอง Full-stack จริง ตั้งแต่ฝั่ง Frontend ไปจนถึง Backend และ Database

ตัวระบบพัฒนาด้วย Next.js (App Router) และเชื่อมต่อกับ MongoDB เพื่อเก็บข้อมูลสินค้า รองรับการเพิ่ม แสดง แก้ไข ค้นหา และดูรายละเอียดสินค้า (CRUD) โดยตั้งใจออกแบบให้โครงสร้างเรียบ เข้าใจง่าย และไม่ซับซ้อนเกินความจำเป็น

3) เทคโนโลยีที่ใช้
- Next.js (App Router)
- React
- MongoDB Atlas
- Mongoose
- styled-components
- Node.js
- Vercel (ใช้สำหรับ deploy)

เลือกใช้ Next.js แบบ App Router เพื่อรวม Frontend และ API ไว้ในโปรเจกต์เดียว ทำให้โครงสร้างชัดและดูแลต่อได้ง่าย

4) โครงสร้างข้อมูล (Database Schema)
ระบบใช้ MongoDB collection ชื่อ products สำหรับเก็บข้อมูลสินค้า โดยมี field หลักดังนี้
- name: ชื่อสินค้า
- code: รหัสสินค้า (ไม่ซ้ำ)
- price: ราคาสินค้า
- description: รายละเอียดสินค้า
- images: URL รูปสินค้า (เก็บเป็น array)
- createdAt, updatedAt: เวลาสร้างและแก้ไขข้อมูล

การออกแบบ schema เน้นความเรียบง่าย
- กำหนดให้ code ไม่ซ้ำ เพื่อใช้อ้างอิงสินค้าและป้องกันข้อมูลซ้ำ
- เก็บรูปเป็น array เผื่อรองรับหลายรูปในอนาคต
- ใช้ timestamps เพื่อช่วยจัดเรียงข้อมูลและติดตามการเปลี่ยนแปลง

5) ฟังก์ชันหลักของระบบ
- Landing Page
- Product List Page
  - แสดงรายการสินค้าทั้งหมดจากฐานข้อมูล
  - รองรับการค้นหาสินค้าด้วยชื่อหรือรหัสสินค้า
- Upload Product Page
  - ใช้สำหรับเพิ่มสินค้าใหม่เข้าสู่ระบบ
  - กรอกข้อมูลพื้นฐานของสินค้า และกำหนดรูปสินค้าเป็น Image URL
- Product Detail Page
  - แสดงรายละเอียดของสินค้าแต่ละรายการ
  - เข้าถึงได้จากการคลิกสินค้าจากหน้า Product List
- Edit Product
  - รองรับการแก้ไขข้อมูลสินค้า
  - ใช้ฟอร์มเดียวกับหน้าการเพิ่มสินค้า เพื่อลดโค้ดซ้ำและคุมความซับซ้อนของระบบ

6) การจัดการรูปภาพ
ในโปรเจกต์นี้เลือกใช้รูปสินค้าเป็น Image URL แทนการอัปโหลดไฟล์จริง เพื่อควบคุมขอบเขตงานให้เหมาะสมกับเวลาการทดสอบ และหลีกเลี่ยงความซับซ้อนจากระบบจัดเก็บไฟล์ภายนอก

7) API Endpoints
- GET /api/products
- POST /api/products
- GET /api/products/[id]
- PUT /api/products/[id]

8) วิธีการรันโปรเจกต์ (Local Development)
- ติดตั้ง dependencies
  - npm install
- สร้างไฟล์ .env.local และกำหนดค่าเชื่อมต่อ MongoDB
  - MONGODB_URI=mongodb+srv://<user>:<password>@<cluster>/<db>
- รันโปรเจกต์
  - npm run dev
- (ถ้ามี) เพิ่มข้อมูลตัวอย่าง
  - npm run seed

9) การ Deploy
- Deploy บน Vercel
- ตั้งค่า Environment Variable (MONGODB_URI) ผ่านหน้า Vercel Dashboard
- ไม่มีการ commit ไฟล์ env ขึ้น repository

10) หมายเหตุสำหรับผู้ตรวจงาน
- โปรเจกต์นี้ตั้งใจทำให้ครอบคลุมการทำงานของระบบสินค้าในมุมมอง Full-stack โดยไม่พยายามใส่ฟีเจอร์เกินความจำเป็น
- มีการเพิ่มฟังก์ชัน Edit และ Product Detail เพื่อแสดงความเข้าใจภาพรวมของระบบ
- โค้ดถูกเขียนโดยเน้นความอ่านง่าย และสามารถนำไปต่อยอดหรือขยายฟังก์ชันเพิ่มเติมได้ในอนาคต
